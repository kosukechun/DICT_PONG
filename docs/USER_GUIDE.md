# DICT_PONG 操作ガイド

## はじめる

プレイヤー名を入力して「コートに参加」を押します。1〜16文字で、文字・数字・空白・`_`・`-`を使えます。`CPU`で始まる名前は使えません。パスワードはありません。同じ名前で参加すると過去の記録を引き継ぎます。

オンラインを選び「対戦相手を探す」を押すと、待機中の人とマッチングします。友だちと遊ぶ場合は「プライベートルームを作る」で表示した6文字のコードを伝えてください。相手が同じURLでコードを入力して参加すると始まります。

CPU戦ではEASY、NORMAL、HARDを選びます。相手の移動速度・反応時間・狙いの誤差が変わります。すべてのモードで5点先取です。

## 動かす

自分のバーは常に左側です。右側のプレイヤーにはコート全体を左右反転して配信しているので、2人とも同じ操作で遊べます。

| 入力 | 操作 |
| --- | --- |
| ↑ / W | 上へ |
| ↓ / S | 下へ |
| ← / A | 左へ |
| → / D | 右へ |
| コート上をドラッグ | 指・マウスの位置を目標に移動 |
| ♪ | 効果音のオン・オフ |
| ⛶ | コートの全画面表示（対応ブラウザ） |

バーは自分の陣地内で、上下左右に動きます。斜め移動でも速度は同じです。キーとドラッグは最後に操作した方を使います。キーやドラッグを離すと止まります。

バーの上下左右・角のいずれでも球を打ち返せます。移動中に当てると球の軌道が変わります。球は上下の壁と、左右のゴール以外の壁で反射します。左右中央の色付きの開口部を通り、球全体が外へ抜けると反対側の人に1点入ります。ゴールの上下端に球が触れた場合も反射します。得点後は中央から再開します。

スマートフォンでは横向きにするとコートを広く使えます。画面の「遊び方」からルールをいつでも確認できます。

## 戦績

ホームの「ラリーの足あと」と「マイ戦績」で、対戦数・勝率・総得点・総失点・プレイ時間を確認できます。CPU戦とオンライン戦は切り替えて集計できます。

「相手別の戦績」には勝ち負け、勝率（%と割）、相手ごとの総得点・プレイ時間を表示します。CPUも難易度ごとに別の相手として集計します。直近30試合の履歴も確認できます。

- 自分で終了した場合、または接続が切れた場合は負けです。相手には勝ちが付きます。スコアは終了時点の値を保存します。
- 途中終了でも5点へ水増ししません。例えば1対2で終了した場合、そのまま記録します。
- 全体停止、サーバーの通常終了、15分の制限時間による中断は勝率・総得点に加算しません。
- プレイ時間は対戦開始から終了まで。開始カウントダウンと中断までの時間も含み、ロビーの待ち時間は含みません。
- サーバーの強制終了や障害の場合、進行中の未確定試合は保存されない場合があります。

## 管理者

名前を小文字の **`chun`** にすると「管理」が表示されます。管理パスワードやキーはありません。誰でもこの名前で管理者になれる仕様です。`Chun`などは別の一般プレイヤーです。

管理画面から全ゲーム停止、日時予約、毎日の時間帯制限を設定できます。**保存ボタンを押すと反映**します。毎日の制限は日本時間、日時指定の予約は端末の現地時間です。開始時刻ちょうどから停止し、終了時刻ちょうどに制限が解除されます。

接続中プレイヤー一覧は5秒ごとに更新します。ゲーム中の相手、オンライン戦かCPU戦か、ロビー・待機状態を確認できます。プレイヤー一覧の「戦績を見る」から他のプレイヤーの相手別成績や履歴を確認できます。

同じ名前は同時に1画面までです。別端末で管理したい場合は、先に開いている `chun` の画面を閉じてから参加してください。
