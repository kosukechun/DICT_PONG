# DICT_PONG 操作ガイド

## はじめる

ホームでプレイヤー名を入力して「名前を登録」を押します。1〜16文字で、文字・数字・空白・`_`・`-`を使えます。`CPU`で始まる名前は使えません。パスワードはありません。同じ名前で参加すると過去の記録を引き継ぎます。

オンラインを選び「対戦相手を探す」を押すと、待機中の人とマッチングします。友だちと遊ぶ場合は「友だち」タブで「プライベートルームを作る」を押し、表示した6文字のコードを伝えてください。相手は同じURLの「友だち」タブでコードを入力して参加すると始まります。

CPU戦ではEASY、NORMAL、HARDを選びます。相手の移動速度・反応時間・狙いの誤差が変わります。すべてのモードで5点先取です。

暗いネイビーと水色のダークモードです。ホームには名前登録・対戦設定だけを表示し、相手待ちやルーム待ちもここで行います。対戦が成立すると、コートを広く使えるゲーム画面に自動で切り替わります。ゲーム中のホーム・戦績への移動は止めています。試合後は結果を確認し、コート上部の「ホームに戻る」で次の対戦を選べます。戦績はメニューの「マイ戦績」でスクロールして確認できます。管理画面も稼働設定・接続中・戦績のタブで切り替えます。

## 動かす

自分のマレットは常に左側です。右側のプレイヤーにはコート全体を左右反転して配信しているので、2人とも同じ操作で遊べます。

ホームの **「操作方法を選ぶ」** で **マウス / WASD** を選んでから試合を始めます。初期設定はマウスです。選択はそのブラウザーに保存され、次回も復元します。保存を無効にしているブラウザーではページを開いている間だけ有効です。相手待ち・対戦中は変更できません。

| 入力 | 操作 |
| --- | --- |
| マウス選択：コート上でカーソルを動かす | マレットがカーソルへ追従（クリック不要） |
| マウス選択：タッチでドラッグ | 指の位置へ移動。離すと停止 |
| W | 上へ |
| S | 下へ |
| A | 左へ |
| D | 右へ |
| W＋Dなどの同時押し | 斜め移動（8方向） |
| 同じ方向を素早く2回押す | その方向へダッシュ |
| Wを押しながらDを2回押す | 右上へダッシュ（他の斜め方向も同様） |
| ♪ | 効果音のオン・オフ |
| ⛶ | コートの全画面表示（対応ブラウザ） |

マレットは自分の陣地内で、上下左右に動きます。斜め移動でも速度は同じです。WASD選択時のみキーで移動・ダッシュでき、マウス選択時はカーソルで移動します。コートの外へマウスを移すと停止します。ウィンドウを切り替えたときも入力を解除します。

マウスの入力はすぐ送信し、自分のマレットはサーバーの返答を待たずに描画します。マウスでは追従の速度制限と補間を外しているため、カーソルを大きく動かしても到着待ちはありません。WASDの通常速度は毎秒520pxです。球の当たり判定と得点はサーバーが確定します。通信回線の往復時間そのものはなくならないため、高遅延時は表示と判定に一時的な差が出る場合があります。

矢印キーでも移動とダブルタップが可能です。2回押しの間隔は250ms以内。キーの長押しではダッシュは発生しません。ダッシュ中は約0.13秒、毎秒1550pxで素早く移動し、通常の毎秒520pxより速く動きます。次のダッシュまで最低0.23秒の間隔が必要です。

スタミナは100で開始し、ダッシュ1回につき35消費します。35未満では通常移動だけができます。最後のダッシュから0.65秒後に毎秒22ずつ自動回復し、最大100まで戻ります。斜めも同じ速さ・同じ消費です。得点してもスタミナは引き継ぎ、サーブ待ちの間も回復します。新しい試合では100に戻ります。コート下のゲージを目安にしてください。

マレットは半径40px（直径80px）の円で、外周のどの向きからでも球を打ち返せます。素早く振ったときも移動経路で判定します。移動中に当てると球の軌道が変わります。球は上下の壁と、左右のゴール以外の壁で反射します。左右中央の色付きの開口部を通り、球全体が外へ抜けると反対側の人に1点入ります。ゴールの上下端に球が触れた場合も反射します。得点後は中央から再開します。

スマートフォンでは横向きにするとコートを広く使えます。画面の「遊び方」からルールをいつでも確認できます。

左右のゴールは太い色付きの枠、ネット模様とGOALの文字で表示します。自陣は水色、相手はオレンジ色です。得点の判定は色付きエリアに触れた時ではなく、球全体が外へ抜けた時です。

## 戦績

「マイ戦績」で、対戦数・勝率・総得点・総失点・プレイ時間を確認できます。CPU戦とオンライン戦は切り替えて集計できます。プレイ画面の下には戦績を表示しないため、コートから下へ移動する必要はありません。

「相手別の戦績」には勝ち負け、勝率（%と割）、相手ごとの総得点・プレイ時間を表示します。CPUも難易度ごとに別の相手として集計します。直近30試合の履歴も確認できます。

- 自分で終了した場合、または接続が切れた場合は負けです。相手には勝ちが付きます。スコアは終了時点の値を保存します。
- 降参は対戦中、コート上部の **「⚑ 降参する」→「降参して終了」** を選びます。「プレイを続ける」なら試合に戻ります。CPU戦とオンライン戦で共通です。確認画面を開いている間も試合は進みます。
- 途中終了でも5点へ水増ししません。例えば1対2で終了した場合、そのまま記録します。
- 全体停止、サーバーの通常終了、15分の制限時間による中断は勝率・総得点に加算しません。
- プレイ時間は対戦開始から終了まで。開始カウントダウンと中断までの時間も含み、ロビーの待ち時間は含みません。
- サーバーの強制終了や障害の場合、進行中の未確定試合は保存されない場合があります。

## 管理者

名前を小文字の **`chun`** にすると「管理」が表示されます。管理パスワードやキーはありません。誰でもこの名前で管理者になれる仕様です。`Chun`などは別の一般プレイヤーです。

管理画面から全ゲーム停止、日時予約、毎日の時間帯制限を設定できます。**保存ボタンを押すと反映**します。毎日の制限は日本時間、日時指定の予約は端末の現地時間です。開始時刻ちょうどから停止し、終了時刻ちょうどに制限が解除されます。

接続中プレイヤー一覧は5秒ごとに更新します。ゲーム中の相手、オンライン戦かCPU戦か、ロビー・待機状態を確認できます。プレイヤー一覧の「戦績を見る」から他のプレイヤーの相手別成績や履歴を確認できます。

同じ名前は同時に1画面までです。別端末で管理したい場合は、先に開いている `chun` の画面を閉じてから参加してください。
