# DICT_PONG 1.5.1 検証結果

検証日：2026-10-29。Windows、Node.js 24.22.1。ローカルの実HTTP/WebSocketサーバーと独立したSQLiteデータを使い、通常の対戦に加えて同時操作・切断・異常入力を検証しました。

全38件が成功、失敗・スキップは0件です。実際の `配布用/PONG-AWS-kit.zip` を展開した環境でも、開発用依存を入れずにオンライン12件・物理ストレス4件、計16件が成功しています。

## 今回の変更

- マレットを半径32pxから40pxへ拡大。直径64pxから80pxへ25%拡大し、描画・衝突・外周と中央線の制限を同じ値から計算します。
- 配布ZIPの場所をプロジェクト直下の `配布用/PONG-AWS-kit.zip` に統一しました。同じフォルダーに `はじめに.txt`、設置手順書、ZIPのSHA-256を置きます。再パッケージ時も自動更新します。
- マウスの直接追従、WASDの移動・ダッシュ、通知なしのAWS構成を維持しています。

## 見つけて修正した不具合

| 不具合 | 再現条件 | 修正と確認 |
| --- | --- | --- |
| パックが上下の壁から一瞬はみ出す | マレットを高速で壁際へ振り、衝突でパックを壁へ押し込む | マレットとの分離後にも壁との衝突を解決。上下の再現テストと固定乱数100系列で範囲を確認 |
| JSONの形式が違うとHTTP 500になる | 名前登録へJSONのnullなどを送る | JSONオブジェクト以外を400として処理し、サーバーを正常に継続 |
| 存在しない特殊なURLがHTTP 500になる | `/__proto__`、`/constructor`、`/toString` へアクセス | 配信対象が自分自身のプロパティであるか確認し、404を返す |
| 日本語の名前が通信の分割で壊れる | UTF-8文字の途中でHTTPの受信チャンクが分かれる | 受信バイトを結合してから一度だけ文字へ変換。日本語の1文字を途中で分割して登録成功を確認 |

## 再実行

開発環境では `npm ci` の後に `npm test`。この作業環境では `.tools/node-v24.22.1-win-x64/node.exe --test --test-concurrency=1 tests/*.test.js` で同じ検証を実行できます。

全体の実行ログは `test-results/full-suite.tap` に保存しています。配布物の検証は次の順で行います。

```text
python scripts/build-guide.py
npm run package
python scripts/verify-package.py
python scripts/smoke-release.py
```

`smoke-release.py` は「配布用」のキットZIPからアプリを取り出し、実行用依存だけで起動した後、オンラインと物理の16件も実行します。

## 検証の限界

6接続・3試合の検証であり、大人数での性能保証ではありません。受信停止と入力再開はローカルでの再現で、実回線の遅延・パケットロスを網羅するものではありません。ブラウザー実機の見た目・音・タッチ・体感遅延、実AWS上のCloudFront経由の対戦と運用機能は未検証です。画面の検証はjsdomによるイベントと描画APIの確認です。
