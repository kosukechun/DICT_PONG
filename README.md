# DICT_PONG

オンライン1対1と、3段階のCPU戦を楽しめるエアホッケーです。横長コート、上下左右に動かせるバー、5点先取。オンラインでも自分は常に左側です。

## AWSに公開する方へ

**Git・GitHub・手元のAWS CLIは使いません。AWSコンソールで操作できます。**

配布用ファイルは `release` フォルダにあります。

| ファイル | 用途 |
| --- | --- |
| `PONG-AWS-kit.zip` | 配布物をまとめたZIP。まずPCで展開します |
| `pong-app.zip` | 展開せず、S3に手動アップロードします |
| `pong-stack.yaml` | CloudFormationに手動アップロードします |
| `AWS_SETUP.html` | ブラウザで読める日本語の設置手順書 |
| `AWS_SETUP.md` | 同じ手順書のMarkdown版 |
| `ARCHITECTURE.svg` | 拡大可能なAWSアーキテクチャ図。ブラウザで開きます |
| `SHA256SUMS.txt` | 配布ファイルのSHA-256 |

順序は **S3にアプリZIP → CloudFormationにYAML → 出力されたGameURLを開く** です。
詳しくは [AWS設置手順](docs/AWS_SETUP.md) をお読みください。

AWSへの実際のデプロイはまだ行っていません。AWS利用料はご自身のアカウントに発生します。

## PCで試す（Windows x64）

1. `pong-app.zip` をPC上の任意のフォルダにすべて展開します。
2. `start-local.cmd` をダブルクリックします。
3. 初回は公式Node.jsをそのフォルダ内にダウンロードして検証します。PC全体のNode.js設定は変更しません。
4. 表示された `http://127.0.0.1:3000` をブラウザで開きます。
5. 終えるときは起動した画面で `Ctrl+C`。画面を閉じるとゲームも停止します。

初回のみインターネットが必要です。Windows ARMやmacOS/LinuxではNode.js 24を別途用意して `npm start` を実行してください。
ローカルで2人の対戦を試すなら、通常ウィンドウとシークレットウィンドウで別々の名前を使います。同じウィンドウ内のタブはログイン情報を共有します。

現在の作業フォルダでPowerShellから起動するコマンド：

```powershell
cd C:\Users\kosuk\script\PONG
.\start-local.cmd
```

起動後は `http://127.0.0.1:3000` を開きます。検証用Node.jsが `.tools` にある場合はそれを使うため、再ダウンロードは不要です。終了は起動したPowerShell画面で `Ctrl+C` を押してください。

## ゲームの機能

画面は暗いネイビーに水色を合わせたダークモードです。ホームには名前登録と対戦設定を表示し、相手待ちの間もホームに留まります。対戦が始まると専用のゲーム画面へ自動で切り替え、終了後は結果を確認して「ホームに戻る」で戻れます。ホームではゲームの描画も停止します。主な操作は16px以上の文字で表示し、戦績は「マイ戦績」にまとめています。

- 名前のみで参加。パスワード不要。同じ名前は同じ戦績を引き継ぎます。
- オンライン：自動マッチング／6文字コードのプライベートルーム。
- CPU：EASY／NORMAL／HARD。反応速度・移動速度・狙いの精度が異なります。
- WASDで移動。同じ方向を250ms以内に2回押すとダッシュ。Wを押しながらDを2回押すと右上にダッシュします。矢印キーでの移動・ダッシュ、ドラッグ移動にも対応。
- スタミナ100、ダッシュ1回35消費。0.65秒後から毎秒22回復。斜めでも移動速度・消費は同じ。ゲージとダッシュの残像を表示。
- ゴール幅を176pxから248pxへ拡大し、得点しやすく調整。
- ゴールは12pxの太い色付き枠とネット・GOAL表示で強調。左右の色を分け、開口部を見分けやすくしています。
- 指定画像 `HTdR38qbIAA86Ob.webp` をロビーに表示。
- バーの上下左右と角で反射。上下の壁で反射し、左右中央のゴールを通り抜けると得点。それ以外の側面は壁で反射。
- 自分はいつでも左側。5点先取。効果音の切替・全画面表示にも対応。
- 対戦中はコート上部の「降参する」から、確認後に試合を終了。現在の得点で自分の負け・相手の勝ちを記録します。CPU戦も同じです。
- 勝敗・勝率（%／割）・対戦相手別成績・総得点・総失点・プレイ時間・直近30試合を表示。
- 名前が **`chun`** の場合だけ管理メニューを表示し、サーバー側でも権限を確認します。管理キーはありません。
- 管理：全ゲーム停止、日時指定の停止、毎日の時間帯制限、日本時間の深夜をまたぐ制限、接続中プレイヤー／相手／モード、各プレイヤーの戦績。
- AWS：日本時間0時にEC2停止・8時に起動（既定）。EC2稼働時間を約1/3減らします。EBS・固定IPv4等の料金は継続します。
- CloudWatch：人数・試合・メモリ・エラー、CPU・通信量・CPUクレジットのダッシュボード。ログは既定7日保存、追加カスタムメトリクスなし。

既存AWS環境には、**ZIP更新とYAMLによるスタック更新の両方**が必要です。[AWS設置手順の「8-A」](docs/AWS_SETUP.md) を参照してください。

名前による識別という指定どおり、名前を知っていれば同じ人の記録を利用でき、`chun` と名乗れば誰でも管理者になれます。大文字・小文字は別名です。`Chun` や `CHUN` に管理権限は付きません。

## 開発・検証

Node.js **24.22.1**、ws **8.22.0**、組み込みSQLiteを使用します。画面はHTML/CSS/JavaScriptとCanvasで、ビルド操作は不要です。

```text
npm ci
npm test
npm start
```

`npm ci` は開発用テスト依存も入れます。配布ZIPには実行に必要な `ws` が入っているので、通常起動やAWS設置にnpm操作は不要です。

Windowsで再梱包する場合：

```text
npm run package
```

Node 24がない現在の作業フォルダでも、検証用の `.tools/node-v24.22.1-win-x64/node.exe` で起動・テストできます。`.tools`、ログ、実行データ、秘密情報は配布に含めません。

## 構成

```text
public/              ゲーム・戦績・管理画面
server/physics.js    衝突判定・移動・CPU・左右反転
server/index.js      HTTP / WebSocket・マッチング・管理
server/store.js      SQLiteへの保存と戦績集計
aws/                CloudFormation・初期設定・バックアップ・更新
docs/               AWS設置手順・操作ガイド・設計と検証
tests/              物理・保存・通信・画面ロジックのテスト
scripts/            ローカル起動・配布ZIPの生成
release/            アップロードする完成配布物
```

補足は [操作ガイド](docs/USER_GUIDE.md) と [設計・検証記録](docs/ARCHITECTURE.md) にあります。
